# 乒乓对决 · Table Tennis Duel

双人乒乓球对抗游戏：支持**常规单机（人机）**、**本地分屏双打**与**局域网/联机对战**，人物采用**火柴人物理骨架**（两段式 IK + 弹簧阻尼惯性），
场地与器材全部按 **ITTF 国际赛事标准**制作。

## 一键开始

```bash
node server.js
```

然后浏览器打开：<http://localhost:8765>

> 零依赖：不需要 `npm install`，Node.js 12+ 即可（推荐 18+）。

## 操作方式

| 动作 | 玩家1（红方） | 玩家2（蓝方） |
| ---- | ---- | ---- |
| 向左移动 | `A` | `←` |
| 向右移动 | `D` | `→` |
| 向前移动 | `W` | `↑` |
| 向后移动 | `S` | `↓` |
| 跑步 | `Shift`（按住） | - |
| 蹲下 | `Ctrl`（按住） | - |
| 推球 | `左键` | `,` |
| 扣球 | `右键` | `.` |

人机与联机模式下，WASD 与方向键均可控制你自己的角色，Shift 跑步、Ctrl 蹲下（蹲下可接任何低球；本地双人仍为 P1/P2 各一组按键）。

**鼠标**：**发球时**移动鼠标瞄准对方半台落点，发球轨迹线实时跟随，单击/右键发球；若瞄准位置解不出合法发球，轨迹线消失且发不出球（需调整瞄准）。**对打时**左键**立即推球**（零延迟）、**右键扣球**；左键推球后 280ms 内按右键可把蓄力期推球**升级为扣球**（本地双人分屏时，左半屏控制 P1、右半屏控制 P2）。

**手机端（竖屏适配，基准 390×844dp）**：左下**浮动摇杆**移动（按下触点处生成，可斜向，隐形热区 160×160），右侧**蹲下按钮**；**发球时点两下屏幕**——第一下进入瞄准，手指移动到哪轨迹跟到哪，第二下发球（瞄准解不出合法发球时轨迹消失、发不出球）；**对打时**单击屏幕推球、**快速上滑扣球**（抬手判定，支持多点触控）。

竖屏排版要点（v3.2.0 起）：
- **主菜单首屏**：标题栏与昵称行各占独立 48dp 且互不遮挡（昵称行点得到、改得到）；其余入口按使用频次排成 2×2 宫格
- **快速开始卡片（难度 + 配色唯一入口）**：难度（简单/中等/困难/地狱，分段控件）与敌我队伍配色（8 色块）、自定义队名全部内联在首屏同一张卡片里，点「快速开始」按当前设置直接开局，无二次弹窗；底部不再有独立的队伍/难度设置面板
- **模拟推演原地展开**：点「模拟推演（AI vs AI）」在原位展开甲/乙的难度、配色与队名（不跳页、不弹全屏 Modal），配好点「开始推演」
- **对战画面中央 55% 不放任何常驻 UI**：「发球」计时移到比分条下方胶囊，球高精确值改为**右缘竖刻度 + 游标**（球进入玩家半台时提亮），地面投影圆保留
- **对战准备页**：两面旗帜整体等比排布（各 139dp，旗杆底部对齐同一水平线，不裁切旗面文字），状态区为等宽倒计时 + 进度条 +「立即开始 / 返回主菜单」出口

**移动范围**：球员可以在以球网线为界的己方半场内自由前后左右移动（台面两侧可以一直走到球网附近），**整身不上桌**（身体/脚部不进入台面正投影）；任意可移动位置都能击球，移动中也能击球。

**比赛页右上角**：⚙ 设置（判定虚线/音乐/音效）、暂停/继续、退出；**人机模式难度在开局菜单选定、对局中锁定**（不可切换）；本地双人可暂停/退出；联机可退出。暂停时物理完全冻结，Esc 键也可暂停（设置面板打开时 Esc 先关设置）。

**设置（右上角 ⚙，主页与比赛页通用）**：**判定范围虚线**（**默认关闭，击败困难模式解锁**；开启后显示球员**接球箱**虚线线框，球进箱变绿高亮并"嘀"提示音，左上角面板显示**球高/进箱**状态——关闭则虚线、提示音与左上角面板**一并隐藏**；v2.4 起不再显示碰撞箱尺寸数字与可扣杀/可高吊判定）、**背景音乐**、**游戏音效**、**音乐音量**、**音效音量**（滑杆 0~100%）、**画质**（**高**/中/低三档，默认高；低=DPR 1 + 跳过观众席，省电流畅；v2.4 手机端高画质 DPR 自动封顶 2 以释放性能）、**帧率上限**（30/60/无上限，默认无上限自动匹配刷新率；物理仍 120Hz 步进，只限渲染频率）；所有开关与音量即改即生效并记忆选择，音乐与音效完全独立。**游戏右上角实时显示真实渲染帧率**（低于 45 变黄提示；实际帧率受浏览器/系统刷新率限制，部分手机浏览器/WebView 固定 60Hz）。

**击球手感**：接球判定为**碰撞箱（进箱即命中）**——以球员为中心、向网前偏移 0.42m 的长方体（1.2m 宽 × 0.8m 深 × 0.7m 高，可接球高 0.70~1.40m）：**球进入箱体后点击推球/扣球即命中**，球拍自动伸向球完成击球动画。**推球**弧线抬高、干净直接过网；**扣球（右键）**更快更狠（约 22m/s+），贴网下压 + 强上旋——**右键只会打出快扣杀**：球够高（≥约 1.0m，左上角"可扣杀 ✓"提示）才能扣过网；球不够高时**直接判定球撞网（对方得分）**，不会降级成慢速球。**蹲下（Ctrl）**把箱体下探到贴地（0.02m）——**任何还在空中的低球都能接起**（说明已并入玩法说明）；蹲得越久移动越慢（速度 ×0.40 → 最低 ×0.20）；**蹲↔站初始瞬发，但 3 秒内反复蹲站会加大转换延迟（每次 +0.15s，最多 0.5s）**。**高吊（推球进阶技巧）**：**蹲下 + 推球**即放出高吊球（高弧线喂到对方半场，逼出扣杀机会）——**仅对普通来球生效**；扣杀来球时保持蹲防推球（接扣杀）；特定角度（球够高、解得出）才有效，左上角"可高吊 ✓"会提示；球太低时自动退回普通防守回球。**反击扣杀（实测）**：扣杀来球用**预判起拍（球到前提前按推球）+ 推球**即可接回去——**站立即可**（实测困难/地狱 AI 扣杀接住 ~47-48%，接住即合法回球）；只有贴地低扣（低于站姿箱底 0.70m）才需要蹲下——蹲下反会降低成功率（箱顶变低漏高位来球）。**扣杀/低平快球来球均有免起拍延迟命中窗**（挥拍 [0, 0.28]s 内、球在箱内即命中，无需等 0.08s 风起，可反应式按键）。**反击扣杀奖励（操作奖励）**：成功反击电脑扣杀（预判起拍+推球接回）时，该回球**视为扣杀**、电脑应对概率**减半**（地狱 0.95→0.475、困难 0.55→0.275）。**低平快球反击奖励（更高档）**：蹲下+推球接回低平快球时，该回球**更高球速 + 刁钻边角落位**，且同样视为扣杀、应对概率减半——回报比反击扣杀更高。

**AI 刻意低球**：困难 AI 有 1/5、地狱 AI 有 1/2 的概率把回球打成**低平快球**——贴网低飞（过网仅数厘米）、落地深而低弹，站立接球箱底 0.70m 处容错极小，**蹲下接最稳**；简单/中等 AI 不打低球。
**AI 高吊球与变招**：困难/地狱/中等 AI 会偶尔放**高吊球**（高弧线喂到对方半场，逼出扣杀机会）；对打两回合不进球后 AI 可能**变招**——改打低平快球/高吊球并横向移动 0.4~0.7m，变招概率随难度与数值提升、未变招越久越高（封顶 100%，变招后清空）。
**AI 应对扣杀**：困难/地狱 AI 接玩家真扣杀为**位置门 × 概率**判定——扣杀落点在 AI 站位 ±0.35m 内且高度/时序成立才算"够得着"，再按档位概率接住（困难 55% → 实测有效反击率约 50%、地狱 95% → 约 80%，等级递增）；打边角/骗位即漏。AI 判定无法扣杀（快扣解不出）时，困难 80% / 地狱 90% 会放弃扣杀改打安全球，剩余 10-20% 冒险出手 = **球撞网失分**（与玩家右键同规则）。

## 赛场氛围

- **观众席**：场地两端与两旁设有**坐姿火柴人观众**（与球员同一画风：圆头 + 骨线骨架），坐在**钢蓝色看台长条座椅**上；**屏幕左侧为己方球迷（红色）、右侧为敌方球迷（蓝色）**（每方视角都如此——P1 红 / P2 蓝各自在左侧看到自己颜色的球迷）；**哪方得分哪方球迷举手欢呼，对方球迷摇头**（约 1.7s 平息）
- **得分掌声**：得分/终局播放**真实录音掌声**（`audio/applause.wav`，3.2s 立体声，尾端淡出防爆音；未加载时用合成掌声兜底），属于游戏音效，受设置中"游戏音效"开关控制（与"背景音乐"独立）；同时观众举手欢呼、起身浮动（约 3 秒）
- **背景音乐（真实 raw 音乐）**：播放真实音乐文件 `audio/music.mp4`（原文件为带视频轨的 mp4，取其音频轨循环播放），由设置中"背景音乐"开关控制，与"游戏音效"**完全独立**；页面打开自动播放（被浏览器拦截时首次点击即响）
- **低机位转播视角**：相机贴近球员高度、视线略抬，球员更大更有临场感，看台如围墙环绕球场

## 模式

- **常规单机 / 无尽人机**：在首页「快速开始」卡片里选难度与双方队伍颜色，点「快速开始」即开局（**对局中难度锁定**），可选**简单 / 中等 / 困难**三档（击败困难解锁**地狱**）——「无尽人机」逐级挑战
  - 简单：反应慢、站位偏、只推球不扣杀，**接球率约 55%**（明显漏接）
  - 中等：反应适中、高球常扣杀（会放高吊/打刁钻角度/变招），**接球率约 95%**
  - 困难：反应快、追位准，高球必扣杀，**接球率约 97.5%**（刻意漏球 <3%），可反击扣杀
  - 地狱：反应/站位/扣杀全面拉满，**0% 刻意漏球**（观战与人机对战一致，完全不再漏球，强版展示）；扣杀激进（smashY 0.95，2~7 扣/局），可反击扣杀；差距全在时机把控与技巧（高吊/刁钻射球/低平快球）
  - **电脑 AI 数值调控**：击败地狱难度后，人机对战的暂停面板变为 4 项 AI 参数滑杆（反应/接球率/攻击性/敏捷，即时生效）——可自定对手机器人强度
  - **个人生涯**：人机对战 / 本地双人对战 / 联机对局每局结束自动记录胜负（后端留最近 60 条）——本地版写入 `records.json`、网页版/桌面公网写入 Cloudflare Durable Object（`GET/POST/DELETE /api/records`，CORS 兼容；DELETE 需 `?token=` 匹配 RECORDS_TOKEN 维护用）；主菜单内「个人生涯」小方框显示总场次/胜率摘要，点击展开整页分页战绩列表（10 条/页：模式 · 胜/负 · 难度 · 比分 · 时间 · 玩家名），无后端/离线时静默不打扰；**手机版（安卓 APK，file:// 页面无同源后端）仅存本地**：战绩写入手机本地 localStorage（卸载/清数据会清空；远程服务器同步功能已在 v2.7.0 移除）
- **本地双人对战**：同一键盘分屏对战，各看各的半场视角。
- **模拟推演（AI vs AI）**：主页点该行**原地展开**配置区（不跳页、不弹全屏 Modal），可分别设定**甲/乙 AI 难度**（简单/中等/困难/地狱，地狱需先在人机模式击败困难解锁）与**甲/乙 旗帜色及队名**，配好点「开始推演」；进入后双方 AI 自动发球、对打、计分；比赛页右上角可**暂停**，暂停面板中可**调整甲/乙 AI 难度**（即时生效）、**微调 4 项 AI 参数**（反应 / 接球率 / 攻击性 / 移动敏捷，滑杆 ×0.5~×1.5 乘到难度基准上，netInfo 出现 ⚙ 表示已微调），或**返回主页面**；观战视角自动跟随。
- **创建联机房间**：生成 4 位房间码；对方在另一台电脑输入房间码加入。
  - 局域网内：另一台电脑访问 `http://本机IP:8765`，在菜单输入房间码。
  - 同一台电脑测试：开两个浏览器标签页即可。
- 服务器为权威模拟：60Hz 固定步长，双方输入统一结算，杜绝不同步。

## 赛事标准尺寸（ITTF）

- 球台：2.74m × 1.525m，台高 0.76m，白线 2cm，双打中线 3mm
- 球网：1.525m 宽（两端与台面边缘相切），网高 0.1525m
- 乒乓球：直径 40mm，质量 2.7g
- 球拍：拍面 15cm × 15cm（正反两面红/黑胶皮），手柄 8.5cm
- 球员身高：1.75m 比例骨架

## 物理与规则

- 真实重力、空气阻力、马格努斯旋转效应、台面反弹与摩擦、旋转在台面反弹时的加速/减速
- 发球必须先落本方半台、再越网落对方半台；触网入界（擦网）重发
- 拦击（球未落台直接击打）判失分；同半台连弹两次判失分
- 11 分制，10 平后净胜 2 分；每 2 分发球轮换，10 平后每分轮换
- 推球带下旋（卸力吸收来球速度），扣球带强上旋（要求击球点较高，否则下网）

## 人物模型（火柴人物理骨架）

- 加粗圆头白线造型：髋→脊柱→肩→颈→头，肩→肘→腕→拍、髋→膝→踝→足均为两段式 IK
- 所有关节带弹簧-阻尼平滑（惯性）：急停、变向、回摆都有动量感
- 头部实时注视球的轨迹；击球后手臂沿动量方向自然回摆
- 身高 1.75m 比例，**球衣与拍面主色跟随旗帜队色**（默认红/蓝色；本地/人机/模拟推演可选 8 种旗帜色，队名限 6 字，装扮不覆盖队服——特效分离 v2.1）；己方视角只显示上半身
- 低机位转播相机（红方视角水平镜像，按键方向与屏幕一致）；球带台面/地面阴影，球台下方有扩散投影阴影（立体感），触台有扩散红圈特效

## 联机说明

- **本地 / 局域网**：`node server.js` 监听 `0.0.0.0:8765`（`PORT` 可改），页面自动走 `ws://localhost:端口`
  - **局域网联机（不借助公网）**：两台设备在同一网络（同一 Wi-Fi / 手机热点 / Radmin VPN 等虚拟局域网）即可：
    1. 房主运行服务器并「创建联机房间」，等待面板会直接显示「对方请打开 `http://本机IP:端口`」（多网卡/Radmin 26.x 全列出，可复制）；
    2. 对方浏览器打开该地址（从房主服务器加载游戏，无需另装），输入 4 位房间码加入；
    3. 首次联机前房主以管理员运行一次 `tools/局域网放行.cmd` 放行防火墙 TCP 8765（Windows 防火墙默认挡入站）；
    4. 房主窗口需保持打开（桌面应用关窗会停掉由它启动的服务器）。
  - 服务器启动会打印全部局域网/VPN 联机地址；`GET /api/info` 返回 `{ version, port, ips }`（启动器据此自动重启旧服务器、房主面板据此显示地址）；控制台每 10s 输出 `[stats]` 诊断（进房卡死时可确认输入是否到达服务器）。
- **公网**：https://ping-pong-duel.pages.dev 直接联机（无需任何端口转发）
  - 架构：Cloudflare Pages 高级模式（`_worker.js`）+ Durable Object（game-room Worker）
  - 联机端点：`wss://ping-pong-duel.pages.dev/ws`（与页面同域）
  - 部署：`npm run deploy:room` → `npm run deploy:pages`（详见 `修改记录.md` 第四节）
