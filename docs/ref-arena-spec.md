## 一·补、v8 / v8b 复制结果（同日第二/三轮）

## 六、验收闭环（不用眼睛）

```powershell
node tools/arena-shot.cjs $env:TEMP\arena            # 程序化场景截图（1280×720）
python tools/arena-compare.py <参考图.jpg> $env:TEMP\arena\free.png
```

指标：区域 bbox IoU（球台/观众带/亮池）、HSV 直方图距离、32×32 单元格 L1、
左右红蓝均衡、亮度分布。每轮把差异写回上表参数，重跑直至指标收敛。
